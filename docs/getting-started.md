# اجرای نسخه فعلی

## به‌روزرسانی فاز PWA — 2026-09-12

برای آفلاین و نصب، `npm run build` و سپس `npm run start` را اجرا کن. یک بار آنلاین باز کن و منتظر «نسخه آفلاین آماده است» بمان؛ سپس تب را ببند و بدون شبکه دوباره باز کن. حالت dev برای بررسی PWA نیست. در استقرار واقعی HTTPS لازم است؛ فعلاً استقرار خارجی انجام نشده.

مسیر درست استودیو `../ai-studio-for-making-digital-product` است. خروجی جدید با `node scripts/studio-phase2.mjs` در `releases/career-compass-0.2.0` ثبت می‌شود. توضیح‌های قدیمی زیر مربوط به فاز قبل‌اند؛ وضعیت PWA را از `docs/phase-2.md` بخوان.

```powershell
npm install
npm run dev
```

مرورگر: `http://localhost:3000`

برای نسخه production: `npm run build` سپس `npm run start`.

۱. شروع سفر را بزن، پاسخ تمرین را بنویس و منتظر وضعیت ذخیره بمان.
۲. ادامه تمرین را بزن؛ تصویر پاسخ شروع و مقصد دلخواه را ببین و تکمیل کن.
۳. بازتاب را بنویس و مرحله را پایان بده. پیشرفت مسیر ۱ از ۹ می‌شود.
۴. صفحه را تازه کن؛ پاسخ‌ها باقی می‌مانند. با مرور و ویرایش، مرحله دوباره قابل انجام است.
۵. پشتیبان JSON بگیر؛ هنگام import جایگزینی داده‌های فعلی تأیید می‌خواهد.

این داده‌ها فقط در همین مرورگر ذخیره می‌شوند. آفلاین فعلی مربوط به صفحه از قبل بازشده است. ورود آفلاین به اپ بسته‌شده هنوز آماده نیست.

## تست و Studio

`npm run test`، `npm run typecheck`، `npm run lint`، `npm run build`، سپس `npm run test:e2e`.

تست مرورگر به Chrome نصب‌شده و پورت آزاد ۳۱۰۰ نیاز دارد و پروفایل موقت مستقل می‌سازد.

`node scripts/catalog-assets.mjs` کاتالوگ ورودی‌ها را به‌روز می‌کند.

`node scripts/export-studio.mjs` snapshot نسخه 0.1.0 را کنار پروژه صادر می‌کند؛ به نوشتن در پوشه sibling نیاز دارد. برای انتشار بعدی شماره نسخه و مسیر release را ارتقا بده. manifest خروجی شامل hash فایل‌هاست.
