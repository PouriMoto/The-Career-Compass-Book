# نسخه کارگاهی بازطراحی — 2026-09-18

## اجرا و بازبینی

`npm run dev` برای ویرایش UI؛ `npm run build` سپس `npm run start` برای PWA. صفحه اصلی تجربه جدید است؛ `/legacy` نسخه قبلی را با دیتابیس قبلی نگه می‌دارد. در صورت مشاهده نسخه cacheشده قدیمی، بعد از ذخیره همه پنجره‌های اپ را ببند و دوباره باز کن.

فهرست سمت راست (منوی مرحله‌ها در موبایل) هر ۹ فصل را برای بررسی آزاد باز می‌کند. مسیر عادی با «ادامه مسیر»، مرور و بازتاب، سپس گزارش فصل و «فصل بعدی» انجام می‌شود. مرحله اول ۱۳ قدم، سایر مرحله‌ها ۵ یا ۶ قدم دارند. این تعداد نسخه اجرایی اولیه است؛ تمام جزئیات storyboard نهایی هنوز پیاده نشده‌اند.

## چیزهایی که اجرا می‌شوند

- Rough.js واقعی با seed ثابت، SVG، مسیر و فلش، چرخ، شبکه و کارت‌های شماتیک.
- فونت محلی Vazirmatn، UI فارسی و RTL، قاب کاغذی، نقشه کنار فعالیت و رنگ ویژه فصل.
- Choice، MultiChoice، Rank با دکمه، Scale، فهرست کارت کوتاه، چرخ با ده حوزه، Review و Reflection انتخابی.
- تعریف محتوای ۹ فصل در `content/fa/guided-course.json`؛ سؤال‌ها داخل component نیستند.
- گزارش هر فصل، اطلس جدا با وضعیت پیش‌نویس/مرورشده/نیازمند مرور؛ نمودار SVG پاسخ‌ها و متن کامل.
- چاپ مرورگر / Save as PDF؛ این خروجی هنوز PDF صفحه‌بندی‌شده نهایی نیست.
- قواعد نمونه با ارجاع به سؤال‌های مبنا؛ unknown معادل صفر نیست.
- ذخیره IndexedDB نسخه ۲، بازگشت به قدم اخیر، کنترل revision، پشتیبان و restore JSON.
- داده v1 هیچ‌جا خودکار به پاسخ جدید تبدیل یا پاک نمی‌شود؛ لینک legacy برای مشاهده آن باقی است.
- cache تولیدی شامل shell جدید، فونت‌ها و legacy است.

## مرز نسخه بازبینی

این نسخه، مسیر قابل کلیک و تکمیل هر نه فصل را برای دریافت نظر درباره UI می‌دهد؛ ادعای تمام‌شدن R1 تا R9 نیست. محتوای اقتباسی هنوز نیازمند بازبینی متن کتاب است. گزارش‌ها برداشت حرفه‌ای یا تشخیص شغلی نیستند.

| بخش تخصصی | وضع فعلی | کار بعد |
|---|---|---|
| History | کارت تجربه + مقیاس/اولویت و گزارش | تاریخ و چندلایه رویداد ساختاریافته |
| Preferences | انتخاب علاقه و rank ارزش‌ها | اتصال مهارت به شاهد و دسته‌بندی چندسبدی |
| Wheel | ثبت مقدار فعلی/مطلوب، چرخ فعلی و قواعد فاصله | overlay مطلوب و انتخاب تصویری مستقیم |
| Choices | گزینه و یادداشت شواهد، اولویت و مجهول‌ها | سلول‌های ساختاریافته منبع/تاریخ/منطقه و ماتریس واقعی |
| Networking | کارت نقش/فرد و سؤال/پیگیری | روابط و حلقه‌های editable مبتنی بر داده |
| Day | کارت بازه و فعالیت کوتاه | زمان typed و validator هم‌پوشانی/۲۴ ساعت |
| Paths | فهرست A/B و شرایط مرور | graph پیش‌نیاز و زمان‌بندی milestone |
| Action | سه برد ۳۰/۶۰/۹۰ روز و منابع | deadline typed، status و dependency |
| Rules | unknown، ظرفیت/افق، اطلاعات ناکافی و gap چرخ | همه قواعد storyboard و شاخه‌های پویا |
| Export | گزارش وب، نقشه SVG داخل آن، print مرورگر | PDF مستقل، دانلود SVG/PNG، snapshot تاریخی |
| Migration | جداسازی امن v1 و v2 | مرور تعاملی و انتقال انتخابی notes |
| AI | خاموش و بدون درخواست شبکه | provider و قرارداد پس از تثبیت تجربه |

تصویر کنار فعالیت غالباً شماتیک است؛ گزارش از داده واقعی استفاده می‌کند اما بیشتر فصل‌ها هنوز layout عمومی کارت‌های متصل دارند. شبکه live از تعداد/نام اشخاص رابطه ساختگی استنتاج نمی‌کند. گزارش wheel مقدارهای فعلی را نشان می‌دهد؛ مقدار مطلوب در کارت‌ها و قواعد gap حاضر است.

## ماژول‌ها

Studio Kit: `guided` (قرارداد/پیشرفت)، `guided-rules` (جمع‌بندی با evidence)، `interactions` (renderer مستقل از عنوان مرحله)، `sketch` (تصویر شماتیک)، `visual-map` (رسم داده گزارش). نام سؤال‌ها و ترتیب مرحله‌ها در content مستقل است. orchestrator و persistence نسخه ۲ فعلاً feature محلی‌اند؛ قبل از استفاده دوم عمومی تلقی نشوند. CSS تعاملات فعلاً همراه stylesheet اپ صادر می‌شود و نیاز به جداسازی دارد.

فونت و dependencyهای جدید در `studio/guided-assets.json` ثبت‌اند. raw assetهای قبلی تغییر نکرده و استفاده نشده‌اند. فقط منابع فونت npm به‌صورت محلی bundle می‌شوند؛ CDN runtime نداریم.

## بررسی‌ها

تست‌های موتور: یکتایی IDها، وجود مرور و بازتاب، جلوگیری از completion بی‌پاسخ، حفظ unknown، stale شدن بدون حذف داده و evidence قواعد. مرورگر: تکمیل هر نه فصل، ماندگاری پس از refresh، خروجی پشتیبان، رندر موبایل/دسکتاپ، بازشدن آفلاین و مسیر legacy. تصاویر `guided-desktop.png` و `guided-mobile.png` برای مرور رابط‌اند. نصب واقعی گوشی و تست upgrade دو build هنوز در backlog است.
